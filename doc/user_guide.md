# Tap Titans 2 자동화 헬퍼 사용 설명서 (Galaxy S24 Ultra)

본 문서는 갤럭시 S24 Ultra (SM-S928N, Android 14+ / One UI 6.1+) 기기에서 **Tap Titans 2 완전 자율 무한 루프 헬퍼**를 설치하고 사용하는 방법을 상세히 안내합니다.

---

## 1. 자동화 무한 루프 동작 원리

헬퍼는 아래의 **5단계 라이프사이클**을 사람이 직접 조작하는 것처럼 자연스럽게 무한 반복합니다.

```
[1. 환생 (Prestige)]
  - 상단 층수 2회 연속 목표치 도달 감지
  - 소드마스터 탭 클릭 -> 하단 스크롤 -> 환생 버튼 클릭 -> 확인 승인
  - 12초간 화이트아웃/리셋 로딩 대기
         ↓
[2. 탭(소드마스터) 레벨업]
  - 레벨업 단위를 MAX로 설정
  - 소드마스터 레벨업 버튼 5연타 -> Lv 600 이상 즉시 확보
         ↓
[3. 스킬 1레벨씩만 해금 (마나 보존)]
  - 레벨업 단위를 'x1'로 전환 (마나 고갈 방지)
  - 1~4번 스킬(천상/치명/마이더스/불꽃) 1레벨 해금
  - 스킬 목록 아래로 스크롤
  - 5~6번 스킬(함성/분신) 1레벨 해금
         ↓
[4. 6대 액티브 스킬 전체 활성화]
  - 하단 탭 닫기 (전투 화면 복귀)
  - 화면 하단 1번부터 6번 액티브 스킬 슬롯 순차 터치
         ↓
[5. 등반 및 상단 층수 감시]
  - 2.5초 간격으로 상단 층수 온디바이스 OCR 판별
  - 등반 중 스킬 꺼짐 방지: 90초 주기마다 6개 스킬 자동 재시전
  - 돌발 요정/광고 팝업 시 뒤로가기(Back) 자동 닫기
  - 외부 앱(카톡, 브라우저 등) 전환 시 터치 자동 일시 정지
         ↓
[목표 층수 도달 시 ➔ 1번 환생으로 복귀하여 무한 반복]
```

## 2. 갤럭시 S24 Ultra 초기 설정 (권한 승인)

앱을 설치하고 처음 실행하면 메인 화면에서 3대 필수 권한을 안내합니다.

### 2.1. [1. 다른 앱 위에 표시 (오버레이)]
- 게임 화면 위에 작은 제어 버블을 띄우기 위해 필요합니다.
- `오버레이 권한 설정` 버튼 클릭 ➔ 목록에서 `TT2 헬퍼` 찾아서 **[허용]** 토글.

### 2.2. [2. 무루트 자동 터치 (접근성 서비스)]
- PC나 루팅 없이 환생 및 스킬 터치를 주입하고, 게임 화면 이탈을 감시하기 위해 필요합니다.
- `접근성 서비스 켜기` 버튼 클릭 ➔ 설치된 앱 ➔ `TT2 헬퍼 자동 터치 및 안전 감시 서비스` 선택 ➔ **[사용 중]**으로 켬.

### 2.3. [3. 배터리 제한 없음 (백그라운드 유지)]
- 이동 중 화면이 켜져 있거나 장시간 구동 시 삼성 One UI가 앱을 절전 모드로 강제 종료하지 않도록 보장합니다.
- `배터리 최적화 예외 등록` 버튼 클릭 ➔ **[허용]** 선택.

## 3. 게임 실행 및 헬퍼 사용법

### 3.1. 메인 화면에서 설정 후 시작 (간편 시작)
1. 앱 메인 화면의 **[4. 자동화 옵션 설정]** 카드에서:
   - **목표 환생 층수**: 원하는 층수 입력 (기본값: `10000`, 필요 시 `15000` 등으로 변경)
   - **헬퍼 시작 시 [소드마스터 렙업 & 6대 스킬 1렙 해금 & 활성화] 즉시 실행**: 체크 유지
   - **등반 중 6대 스킬 주기적 재활성화**: 체크 유지
2. 하단의 **[TT2 자동화 헬퍼 시작 (화면 캡처 실행)]** 버튼을 누릅니다.
3. Android 14 화면 캡처 권한 창에서 **[전체 화면]** (또는 단일 앱에서 Tap Titans 2) 선택 후 **[시작]**을 누릅니다.
4. 앱이 자동으로 백그라운드로 내려가며 화면에 **플로팅 버블 아이콘(녹색 RUN 표시)**이 나타납니다.
5. **Tap Titans 2 게임 화면으로 진입**하면:
   - 헬퍼가 즉시 소드마스터 탭 열기 ➔ MAX 레벨업 ➔ x1 전환 ➔ 6대 스킬 1레벨씩만 해금 ➔ 6대 액티브 스킬 전체 순차 시전을 전자동으로 수행합니다!
   - 세팅이 완료되면 자동으로 **층수 감시 모드**로 전환되어 등반을 시작합니다.

## 4. 플로팅 오버레이 상세 패널 및 수동 제어

화면에 떠 있는 플로팅 버블을 가볍게 터치하면 상세 제어 패널이 열립니다:
- **[지금 즉시 스킬 1렙 해금 & 활성화] 버튼**:
  - 게임 플레이 도중 언제든지 스킬을 즉시 1레벨씩 찍고 켜고 싶을 때 누르면 즉시 실행됩니다.
- **[환생 & 전체 루프 즉시 테스트] 버튼**:
  - 목표 층수를 기다리지 않고 `환생 ➔ 탭업 ➔ 스킬 1렙 해금 ➔ 활성화` 전체 사이클이 잘 돌아가는지 테스트할 때 사용합니다.
- **실시간 인식 층수 모니터링**:
  - 상단 층수가 실시간으로 정상 인식되고 있는지 패널에서 바로 확인 가능합니다.

## 5. 자주 묻는 질문 (FAQ) & 트러블슈팅

### Q1. 게임 외 다른 앱(카톡, 웹서핑)을 볼 때 터치가 잘못 눌리면 어쩌죠?
- 헬퍼는 접근성 이벤트를 통해 현재 전면(Foreground) 화면이 `com.gamehivecorp.taptitans2`인지 밀리초 단위로 실시간 확인합니다.
- 카톡 창이나 홈 화면으로 나가면 **터치 주입이 즉시 일시 정지**되므로 오작동 사고가 발생하지 않습니다.

### Q2. 층수 인식이 잘 안 될 때는 어떻게 하나요?
- 헬퍼는 Google ML Kit 온디바이스 NPU 모델과 명암 대비 1.5배 전처리를 사용하여 폰트나 배경 이펙트를 완벽하게 걸러냅니다.
- 만약 게임 설정에서 숫자가 `15.4K` 또는 `15,400` 등으로 표시되더라도 정규식 파서가 모두 정상 변환합니다.

### Q3. 배터리 소모는 심하지 않나요?
- 동영상 스트리밍 방식이 아니라 2.5초에 단 1회, 그것도 상단 층수 영역만 수 킬로바이트(KB) 크기로 잘라내어 분석하므로 CPU 점유율이 1% 내외로 유지됩니다.
